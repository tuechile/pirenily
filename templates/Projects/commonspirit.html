CommonSpirit Health is the largest nonprofit health system in the U.S., with 138 hospitals in 24 states. Its Community Investment Program (CIP) lends money, mostly below market rate, to groups working on the social causes of poor health in those communities. To decide where it goes, staff read each hospital's Community Health Needs Assessment (CHNA).

A T4SG team built an analysis tool for this the year before. It worked, but staff still couldn't compare a health priority across hospitals, regions or years, and the color-heavy, text-heavy dashboard felt "overwhelming". So they kept going back to the PDFs.

How might CIP staff compare health priorities across 200+ communities without reading every report?

{% endcall %} {{ cs.section("Research", lead="I interviewed 6 CommonSpirit board members one on one") }} {{ cs.insights("Four pain points", [ ("Reading by hand", "Staff read 50–60 CHNA PDFs a year to pull out the key points."), ("No lookup across regions", "There was no way to find one priority across regions, and terms like \"access to care\" stayed vague."), ("Stale between cycles", "CHNAs update every three years, so the tool went stale in between."), ("No link between hospitals", "Hospitals couldn't see who shared a priority or compare communities over time."), ]) }} {{ cs.section("Idea", lead="We cut the tool down to four pages") }} {% call cs.media_text(img('ux', 'commonspirit/impact-effort.png'), "Impact x Effort prioritization board mapping feature ideas from research") %}

We ranked every idea from research (KPI numbers, region maps, hospital comparison charts, batch upload, notes and more) by impact and effort. That decided what came first and what we left out on purpose.

{% endcall %} {% call cs.section() %}

Four pages made the cut. Home holds the numbers staff check first. Regional exists because many priorities turned out to be shared well beyond one city. Compare was the CIP team's original ask. Trends kept the one part of the old tool staff praised most.

Four pages plus settings didn't fit in the old top nav, so we moved it to a left sidebar. We also swapped the generic dashboard theme for CommonSpirit's own colors, so the tool looked like theirs.

{% endcall %} {% call cs.section("My Contribution", lead="I rebuilt Settings from one bare screen into a Preferences flow") %}

Besides the system design, I owned Account and Settings. The old page was a single dark screen with a username, an email and a bio, so I split it in two. That way the first chart staff see already matches how they work.

{% endcall %} {{ cs.boxes([ ("Account", "Profile with role and avatar, plus password, two-factor login and data export."), ("Preferences", "Default chart colors, contrast, sorting, document sets and geography level."), ], title="How I split it") }} {{ cs.figure(img('ux', 'commonspirit/redes1.webp'), "CommonSpirit Health redesign, Preferences page", size="lg", caption="Preferences, renamed from \"General\" once it held chart, sorting and geography defaults.") }} {{ cs.figure(img('ux', 'commonspirit/redes2.webp'), "CommonSpirit Health redesign, Account page", size="lg", caption="Account opens straight from the profile card, so it's the first settings screen staff see.") }} {% call cs.section("Testing", lead="The same decisions took less time on the redesign") %}

In the 1:1 interviews, all 6 board members worked through the same decisions on the old tool and on our redesign while we timed each one.

{% endcall %} {{ cs.stats([ ("35%", "less time per task than the old tool, projected from testing"), ]) }} {% call cs.section() %}

How we measured it: from those timed sessions we project about 35% less time per task. That figure comes from testing, not from use.

{% endcall %} {% call cs.section("Reflection", lead="In a tool people open every day, small system choices matter most") %}

Where the nav lives, how many clicks it takes to reach a comparison, whether the colors feel like theirs: these mattered as much as any single screen. Using CommonSpirit's own palette made the tool feel like it belonged to them, not to an outside team.

It's also the choice I'd test next. CommonSpirit's palette is mostly magenta, and the comparison charts already use color to tell series apart. Next time I'd check contrast and colorblind-safe options before putting brand colors that strong inside the charts themselves.

Status: shipped. I wrote the handoff document, and a T4SG engineering team built on it over the summer (backend and a Supabase trial). I wasn't on that build.

What we'd track after launch: how long it takes to compare one priority across hospitals, against reading the PDFs by hand.

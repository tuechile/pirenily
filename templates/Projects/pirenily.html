Templates made every portfolio look the same. I wanted a site that reads like a personal archive: dark, quiet and a little dreamy, where the work sits in a frame I designed myself.

{% endcall %} {% call cs.section("First Website", lead="December 8, 2024") %}

Pirenily started as my first ever website, built in one sitting on December 8, 2024: 32 commits between 3:37 in the afternoon and 10:57 at night, starting from a Flask template. It was the first time I wrote code for something of my own.

Most of what defines the site now was already there that night: the search bar on the landing page cycling through my names, the loader GIF between pages, BHN Cinema for the logo and Crimson Text for everything else. What changed is everything around them.

{% endcall %} {{ cs.cta("https://pirenily.com/pirenily-2024/", "Visit the 2024 site", kicker="As of December 8, 2024") }} {% call cs.section("Stack", lead="Small on purpose") %}

The site is a Flask app with Jinja2 templates and vanilla HTML, CSS and JavaScript. There is no database and no build step: pushing to main redeploys it on Koyeb.

— One base layout every page extends, plus case-study building blocks (hero, sections, rows, callouts) shared as Jinja macros
— Images go through one helper that picks a web-sized copy and fingerprints the URL
— A version number on every stylesheet and script, bumped on each change, so browsers never serve a stale one

{% endcall %} {{ cs.placeholder("Diagram: request → Flask route → Jinja template → page") }} {% call cs.section("Aesthetic", lead="Quiet, serif, a little dreamy") %}

Black background, gray text, near-white titles and a single teal accent. BHN Cinema only for the Pirenily logo; Crimson Text, often italic, for everything else.

Hovering blurs things slightly instead of changing their color. Panels are frosted glass with hairline borders. Things appear and disappear instantly, with no fades.

{% endcall %} {% call cs.row("pair", caption="My view and Your view, side by side.") %} {{ cs.placeholder("My view (dark, serif)") }} {{ cs.placeholder("Your view (light, sans)") }} {% endcall %} {% call cs.section("Two Views", lead="Two switches instead of a settings panel") %}

The nav has a light switch and a sound switch. Light on is Your view: a beige paper theme, a system sans font and larger sizes, for anyone who just wants to read. Light off is My view, the site as I see it.

Every color comes from a small set of tokens, so one switch repaints the whole site, icons included. The sound switch turns on music and click sounds.

{% endcall %} {% call cs.section("The Finder", lead="Search instead of a menu") %}

The landing page opens on a search bar that cycles through my names (Pirenily, Chi Le, Iron Pig, Emily, Chi Bell). Type anything and it finds the closest page, forgiving accents, missing spaces, half-typed words and typos. If nothing matches, it opens a random page.

{% endcall %} {{ cs.placeholder("Screen recording: typing into the finder") }} {% call cs.section("Drawn by Hand", lead="Every icon is a line drawing") %}

No icon libraries or logo files. Each icon is one of my own line drawings, stroked in the current text color, so it follows every theme without a second version.
